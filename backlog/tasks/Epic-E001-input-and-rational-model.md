# Epic E001 — Input and Rational Model

## Objective
Establish the input representation and mathematical model for the rational function.

## Scope
Implement command-line vector parsing, floating-point polynomial storage and operations, and rational-function state.

## Tasks

- Task E001.001 — Parse command-line coefficient vectors
- Task E001.002 — Implement polynomial representation and operations
- Task E001.003 — Implement rational-function representation

## Completion Criteria

The application can accept the documented two-vector command-line format and represent the resulting rational function.
