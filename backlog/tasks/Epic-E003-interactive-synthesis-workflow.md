# Epic E003 — Interactive Synthesis Workflow

## Objective
Coordinate the interactive removal loop and maintain synthesis progress.

## Scope
Track removals and components, handle user choices, update the current state, and apply completion rules.

## Tasks

- Task E003.001 — Track synthesis state
- Task E003.002 — Handle interactive selections
- Task E003.003 — Run the synthesis loop

## Completion Criteria

The controller supports selection, invalid-input reprompting, `q` termination, state updates, and no-poles completion.
