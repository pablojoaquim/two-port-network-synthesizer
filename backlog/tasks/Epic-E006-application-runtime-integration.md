# Epic E006 — Application Runtime Integration

## Objective
Connect the implemented synthesis workflow to the command-line application entry point.

## Scope
Build the rational-function model from parsed arguments, start the interactive synthesis controller, verify the executable workflow, and keep the runnable example aligned with the implementation.

## Tasks

- Task E006.001 — Connect the application entry point to synthesis
- Task E006.002 — Add end-to-end application workflow coverage
- Task E006.003 — Document and verify interactive application execution

## Completion Criteria

The built application parses its documented inputs, starts the synthesis workflow, accepts interactive input, and produces the documented complete or partial synthesis output. The executable path is covered by automated tests and a runnable example.
