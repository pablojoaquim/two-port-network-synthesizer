# Epic E002 — Total Removal Analysis

## Objective
Analyze the current rational function and determine valid total removals using the Foster method.

## Scope
Identify poles and removal options, validate removals, and obtain component types and values.

## Tasks

- Task E002.001 — Identify poles and removal options
- Task E002.002 — Validate total removals
- Task E002.003 — Extract Foster component data

## Completion Criteria

The analysis can return valid removal options and the corresponding Foster component information, or report that no removal can be performed.
